tab-triage

Install tab-triage

About a minute, in Chrome or any Chromium browser (Edge, Brave, Arc). No account and no API key.

This browser doesn't look like Chrome or another Chromium browser. tab-triage needs one of those.

Download tab-triage (zip)

Version 1.0. Chrome only lets the Web Store install extensions automatically, so for now there are four short steps. A Chrome Web Store version is on its way.

  1. Unzip it

    Open the downloaded tab-triage.zip. You'll get a folder called tab-triage. Move it somewhere it can stay, such as your Documents folder: Chrome loads the extension from that folder, so don't delete it.

  2. Open the extensions page

    Paste this into the address bar and press Enter (websites aren't allowed to link to it):

    chrome://extensions

  3. Turn on Developer mode

    Use the switch in the top-right corner of that page.

  4. Load it

    Click Load unpacked and choose the tab-triage folder from step 1. The tab-triage settings page opens: read what gets sent, then press I understand, enable sorting.

Then

Click the puzzle-piece icon in the toolbar and pin tab-triage. Open some tabs, click its icon, and press Sort tabs. Undo puts everything back.

Good to know

  • Chrome may show a reminder that a developer-mode extension is installed. That's expected for anything not from the Web Store; choose to keep it.
  • It doesn't update itself. Download it again from this page and press the reload icon on its card in chrome://extensions.
  • To remove it, press Remove on its card. That deletes everything it stored.
  • What it sends and keeps: the privacy policy. The source is on GitHub.
